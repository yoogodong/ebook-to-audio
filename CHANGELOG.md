# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-11-06

### Highlights

- Added chaptered M4B export with chapter markers, metadata, and optional cover images.
- Added EPUB 2 and EPUB 3 input with spine-based reading order, nav/NCX tables of contents, and heading fallback.
- Added resumable conversions with per-chunk and per-chapter caches.
- Added concurrent synthesis, automatic retries, and optional merged MP3 output.
- Added a PyQt5 desktop interface with drag and drop, voice selection, preview, progress, and cancellation.
- Added bilingual English and Simplified Chinese documentation.
- Released the project under GPL-3.0-only.

### 版本亮点

- 支持带章节标记、元数据和可选封面的 M4B 导出。
- 支持 EPUB 2 / EPUB 3，按 spine 阅读顺序解析，并兼容 nav / NCX 目录和标题兜底。
- 支持按音频块和章节断点续传。
- 支持并发合成、失败重试和可选的全书 MP3 合并。
- 提供 PyQt5 图形界面，支持拖放、音色选择、试听、进度和取消。
- 提供英文和简体中文双语文档。
- 项目采用 GPL-3.0-only 许可证。
